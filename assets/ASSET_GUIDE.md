# SafeKid Assets Guide

## Brand
- `brand/safekid-logo-original.webp` — canonical owner-supplied logo. Keep unchanged.
- `brand/safekid-logo-trimmed.png` — same artwork with transparent outer canvas trimmed and modest clear space added; use for ordinary placement.

## Visual references
- `reference/reference-habit-app-ui.jpg` — primary reference for mobile habit-app composition, onboarding, friendly illustration use and navigation. Reference only; do not embed its screens in the product.
- `reference/reference-visual-moodboard.jpg` — secondary moodboard for soft modular surfaces and playful illustration placement. It contains unrelated product UIs; select only the relevant visual cues.

## Asset policy
See `docs/14_VISUAL_ART_DIRECTION_AND_ASSET_RULES.md` and `docs/16_AGENT_SKILLS_AND_VISUAL_QA.md`. Any new externally sourced asset must be documented in root `ASSET_CREDITS.md`, with source and license. Do not alter the canonical logo.
